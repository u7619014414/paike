# 学生选课系统 - 快速开始指南

## 问题现象
✗ 学生登录后界面全是灰色
✗ 无法选择任何课程
✗ 课程表为空或显示"暂无课程"

## 原因分析
数据库中缺少基础数据（时间段、教室、课程、课程安排等）

**选择以下任一方式：**

```

```

```bash

mvn spring-boot:run -DskipTests
```

等待看到：`Started StudentCourseApplication in X.XX seconds`

#### 启动前端
```bash
cd D:\1vueproj\paike\student-course\student-course-frontend
pnpm dev
```
等待看到：`Local: http://localhost:3000`

2. 使用测试账号登录：

## 验证成功的标志

登录后，您应该看到：

1. **学生信息卡片**
   - 显示学生姓名、年龄、年龄组
   - 显示家长信息

2. **课程表格**
   - 7列（周一到周日）
   - 4行（早班、中班、晚班、夜班）
   - 对应年龄组的课程以彩色卡片显示

3. **课程卡片**
   - 显示课程名称
   - 显示教室名称
   - 显示教师名称
   - 显示当前人数/最大人数
   - 有"选课"按钮（可选课程）

## 课程颜色说明

- 🟦 **蓝色边框** - 本年龄组可选的空课程（无人选）
- 🟧 **橙色边框** - 本年龄组可选且有人选的课程
- 🟥 **红色边框** - 课程已满，无法选择
- ⬜ **灰色背景** - 其他年龄组的课程，不可选择

## 常见问题

### Q1: 导入数据后，点击"当前周"仍然没有课程？
**A**: 刷新浏览器页面（Ctrl+F5），或者检查浏览器控制台是否有错误。

### Q2: 所有课程都是灰色？
**A**: 这是正常的！灰色表示该课程不属于当前学生的年龄组。请使用匹配年龄组的测试账号登录。

### Q3: 能看到课程但无法选课（按钮是灰色的）？
**A**: 检查该课程是否已满员（当前人数 >= 最大人数），已满的课程无法选择。

### Q4: 导入脚本报错 "mysql: command not found"？
**A**: 系统未安装MySQL客户端或未添加到PATH。请使用MySQL Workbench等图形化工具手动执行 `init-student-data.sql`。

### Q5: 能登录但课程表完全空白（连"暂无课程"都不显示）？
**A**:
1. 检查后端是否正常运行（访问 http://localhost:45081/api/time-slots/all 应返回JSON数据）
2. 检查浏览器控制台的Network标签，是否有API请求失败
3. 检查后端日志是否有SQL错误
