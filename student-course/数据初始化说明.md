## 快速导入数据

### 方式1：使用批处理脚本（推荐）

1. 确保MySQL客户端已安装并在PATH中
2. 双击运行 `import-init-data.bat`
3. 按照提示操作

### 方式2：手动导入

打开命令行，执行：

```bash
cd D:\1vueproj\paike\student-course
mysql -h asdnn.com -P 45306 -u school_user -pschool_pass123 school_system < init-student-data.sql
```

### 方式3：使用MySQL客户端

1. 打开MySQL Workbench或其他客户端
2. 连接到数据库：
   - Host: asdnn.com
   - Port: 45306
   - User: school_user
   - Password: school_pass123
   - Database: school_system
3. 打开并执行 `init-student-data.sql` 文件

## 注意事项

1. **数据清空警告**：执行初始化脚本会清空以下表的数据：
   - S_STUDENT_ENROLLMENTS（学生选课记录）
   - T_COURSE_SCHEDULE（课程安排）
   - S_STUDENTS（学生信息）
   - K_COURSES（课程信息）
   - J_CLASSROOMS（教室信息）
   - T_TIME_SLOTS（时间段信息）

2. **日期动态生成**：课程安排日期基于当前周的周一动态生成，确保总是显示当前周的课程

3. **教室容量**：每个教室设置了最大容量，但课程的最大学生数由课程本身设定

4. **选课逻辑**：
   - 学生只能选择匹配自己年龄组的课程
   - 课程未满时显示可选
   - 课程已满时显示"已满"且不可选

## 故障排查

### 问题1：导入脚本执行失败
- **原因**：MySQL客户端未安装或不在PATH中
- **解决**：安装MySQL客户端并添加到系统PATH

### 问题2：连接数据库失败
- **原因**：数据库连接信息错误或数据库服务未启动
- **解决**：检查 `application-dev.yml` 中的数据库配置

### 问题3：登录后仍然没有课程显示
- **原因1**：前端请求的日期范围与数据库中的课程日期不匹配
- **解决**：点击前端的"当前周"按钮刷新到本周

- **原因2**：学生年龄组与课程年龄组不匹配
- **解决**：确认使用的测试账号年龄组与想查看的课程年龄组一致

- **原因3**：后端服务未正常启动或前端代理配置错误
- **解决**：检查后端日志，确认服务运行在45081端口

### 问题4：课程都显示灰色
- **原因**：学生年龄组与所有显示的课程年龄组都不匹配
- **解决**：系统正常，因为灰色表示"其他年龄组的课程"。切换到匹配的测试账号即可看到彩色可选课程
