# 学生选课系统 - 移动端项目说明

## 项目概述

这是一个专为移动设备优化的学生选课管理系统,使用现代化的移动端技术栈构建,提供简约易用的界面和流畅的操作体验。

## 核心功能

### 1. 用户认证
- **学生登录**: 使用学号和密码登录
- **学生注册**: 填写基本信息在线注册,系统自动生成学号
- **JWT认证**: 安全的 Token 认证机制

### 2. 选课中心
- **课程表查看**: 按周显示课程安排
- **课程详情**: 查看教室、时间、教师、人数等信息
- **在线选课**: 点击课程卡片即可选课
- **取消选课**: 点击已选课程可取消
- **实时更新**: 课程容量和状态实时显示
- **周导航**: 支持查看上周/下周课程

### 3. 学生管理
- **学生列表**: 浏览所有学生信息
- **年龄组筛选**: 按年龄组筛选学生
- **搜索功能**: 快速搜索学生姓名或学号
- **学生详情**: 查看完整的学生信息

### 4. 个人中心
- **个人信息**: 查看学号、姓名、年龄等信息
- **已选课程**: 统计和查看所有已选课程
- **家长信息**: 查看家长联系方式,支持一键拨号
- **系统信息**: 查看关于系统的信息
- **退出登录**: 安全退出系统

## 技术特点

### UI 设计
- **简约风格**: 清爽简洁的界面设计
- **渐变背景**: 优雅的紫色渐变主题
- **卡片布局**: 信息层次清晰

- **弹窗交互**: 流畅的弹窗动画
- **加载提示**: Loading 和 Toast 提示
- **确认对话框**: 重要操作需要确认

### 响应式设计
- **移动优先**: 专为移动端设计
- **自适应布局**: 适配不同屏幕尺寸
- **安全区域**: 支持刘海屏等异形屏
- **触摸手势**: 支持滑动等手势操作

## 快速启动

### 方法一: 使用启动脚本 (推荐)

双击 `start-mobile.bat` 即可自动启动项目。

### 方法二: 命令行启动

```bash
# 1. 进入项目目录
cd student-course-mobile

# 2. 安装依赖 (首次运行)
pnpm install

# 3. 启动开发服务器
pnpm dev
```

### 访问地址

- **本地访问**: http://localhost:3001
- **局域网访问**: http://[你的IP]:3001 (手机访问)

## 开发规范

### 代码风格
- TypeScript 严格模式
- Vue 3 Composition API
- 使用 `<script setup>` 语法
- SCSS 模块化样式

### 命名规范
- 组件: PascalCase (如 `CourseSelection.vue`)
- 变量/函数: camelCase (如 `handleLogin`)
- 常量: UPPER_CASE (如 `AGE_GROUPS`)
- CSS类: kebab-case (如 `student-card`)

### API 调用
- 统一使用 `api/index.ts` 中定义的 API 函数
- 错误处理由 Axios 拦截器统一处理
- Loading 状态自动管理

## 调试技巧

### Chrome DevTools 移动调试
1. 打开 Chrome DevTools (F12)
2. 点击设备工具栏图标 (Ctrl+Shift+M)
3. 选择设备型号 (如 iPhone 12 Pro)
4. 访问 http://localhost:3001

### 真机调试
1. 确保电脑和手机在同一WiFi
2. 查看电脑IP: `ipconfig` (Windows) 或 `ifconfig` (Mac/Linux)
3. 在手机浏览器访问: `http://[电脑IP]:3001`

## 注意事项

1. **后端依赖**: 需要后端服务运行在 `localhost:45081`
2. **数据库**: 确保数据库有测试数据
3. **端口占用**: 默认 3001 端口,如冲突可在 `vite.config.ts` 修改
4. **网络**: 真机调试需要同一局域网

## 故障排除

### 问题: 依赖安装失败
```bash
# 清除缓存
pnpm store prune
# 重新安装
rm -rf node_modules
pnpm install
```

### 问题: 端口被占用
修改 `vite.config.ts`:
```typescript
server: {
  port: 3002  // 改为其他端口
}
```

### 问题: 无法连接后端
检查:
1. 后端是否运行在 45081 端口
2. `vite.config.ts` 代理配置是否正确
3. 浏览器控制台是否有错误

### 问题: 样式不生效
1. 检查 SCSS 语法是否正确
2. 检查 Vant 组件是否正确导入
3. 清除浏览器缓存
